# One Line of Earned Pride

Entry for the make.fun competition
[u-mang-one-line-of-earned-pride-a0138557](https://make.fun/competitions/u-mang-one-line-of-earned-pride-a0138557):
a program that writes one line — a quiet, earned moment of pride — to
`/output/entry.txt`.

The line: *After three years of burnt loaves, the baker's apprentice pulled
out a loaf that sang as it cooled, and the old baker just nodded.*

Run with Node 22.18+:

```
node main.ts
```

It validates the line (1–240 characters, single line) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
